## Projects

- **[myobridge](https://github.com/ethsanders/myobridge)**: An ESP32 streams four MyoWare EMG sensors at 1 kHz over WiFi, and a Python library filters the signal, watches each electrode, and decodes hand gestures live. Its gesture sets keep a 90% coverage promise at 89.1% across 91 later days, vs. 74.6% the textbook way. Benchmarked on the public 3DC and MultiDay datasets, 117 µs per 20 ms packet, 354 passing tests. [Live demo](https://ethsanders.github.io/myobridge/demo/)
- **[rj_convert](https://github.com/RoboJackets/robocup-software)** (RoboJackets RoboCup): rewrote the stack's ROS 2 message-conversion layer onto ROS 2 Humble type adapters (REP 2007) with C++ templates, and fixed a recursion bug along the way. Merged into the team's main branch in November 2026.
- **[Ball speed sensor](https://github.com/RoboJackets/robocup-rustware/tree/miniprojects/ball-speed-measurement)** (RoboJackets RoboCup): prototype Rust/RTIC firmware on a Teensy 4.1 that times a ball through laser gates and fits its speed.
- **Kimchi** (RoboJackets): helped build a 3 lb rookie combat robot.
- **[RJ_RI3D_2026](https://github.com/RoboJackets/RJ_RI3D_2026)** (RoboJackets): Robot in 3 Days. Intake, shooter and auto-align code in Java/WPILib.
